# Controle IID auto-normalizado

Reexecução integrada do TOY conjugado e controle negativo raro. As seis matrizes geradas são bit a bit iguais às do ensaio preparatório; os sete critérios congelados passaram. Não é uma campanha PTA nem prova de que todas as caudas de uma proposta foram visitadas.

Receita: `.venv/bin/python scripts/validar_diagnosticos_iid_toy.py`. O comando recusa sobrescrever este relatório; para repetir, use um checkout de reprodução sem os produtos gerados e mantenha os registros publicados.
