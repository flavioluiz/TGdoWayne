# Dados e ORFs do piloto C07

Os 16 sorteios contínuos foram gerados antes dos testes de integração, com a configuração `configs/calibration/pilot_initial.json`. Este conjunto foi copiado sem alteração do piloto preparatório. Não é uma campanha SBC500.

As ORFs registram resoluções comuns, assinatura da configuração, erro de refinamento e custos. A existência de cache não constitui validação independente de todos os pares. Sete pares foram comparados com quadratura direta; a reprodução integrada é registrada separadamente. Não excluir realizações difíceis nem selecionar verdades a partir dos nós de integração.
